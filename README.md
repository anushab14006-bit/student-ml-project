# 🎓 Student Performance Prediction System

## 📌 Overview

This project predicts whether a student will **PASS or FAIL** based on academic features like G1, G2, and study time using a Machine Learning model.
It is a full-stack application integrating **Machine Learning + Backend + API + Frontend**.

---

## 🚀 Tech Stack

* Python (Machine Learning)
* Flask (ML API)
* Spring Boot (Backend)
* HTML, JavaScript (Frontend)

---

## 🧠 Machine Learning

* **Model:** Random Forest Classifier
* **Accuracy:** ~91%

### Features Used:

* G1 (First Period Grade)
* G2 (Second Period Grade)
* Study Time

---

## 🔗 System Architecture

```
Frontend → Spring Boot → Flask API → ML Model → Result
```

---

## ⚙️ Features

* Predict student performance (**PASS / FAIL**)
* REST API integration between Java and Python
* End-to-end full-stack ML system
* Real-time prediction using trained model
