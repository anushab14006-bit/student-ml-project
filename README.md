# Student Performance Prediction System

## 📌 Overview

This project predicts whether a student will PASS or FAIL based on input features like G1, G2, and study time using a Machine Learning model.

## 🚀 Tech Stack

* Python (Machine Learning)
* Flask (API for ML model)
* Spring Boot (Backend)
* HTML (Frontend)

## 🧠 Machine Learning

* Model: Random Forest Classifier
* Accuracy: ~91%
* Features used: G1, G2, Study Time

## 🔗 System Architecture

Frontend → Spring Boot → Flask API → ML Model → Result

## ⚙️ Features

* Predict student performance (PASS/FAIL)
* REST API integration
* Full-stack ML system

## ▶️ How to Run

### 1. Run Flask

python app.py

### 2. Run Spring Boot

Run your Spring Boot application

### 3. Open Frontend

http://localhost:8080/index.html

## 📊 Example Input

G1: 10
G2: 12
Study Time: 2

## 📈 Output

PASS / FAIL
